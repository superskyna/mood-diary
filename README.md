# 감정일기

매일 있었던 일과 감정을 기록하고 월간 감정 통계로 돌아보는 개인용 웹서비스 프로젝트다. 검정과 흰색 중심의 차분한 무채색 화면을 사용한다.

## 현재 상태

첫 버전 개발이 완료되었다. 달력에서 날짜를 골라 감정일기를 저장·수정·삭제할 수 있고, 분석 페이지에서 월별 감정 횟수와 관련 기록을 볼 수 있다. JSON 파일을 이용한 전체 기록 백업과 복구도 지원한다. 자세한 완료 기록은 `PROJECT_PROGRESS.md`에서 확인한다.

## 프로젝트 문서

- `PRD.md`: 제품 목표와 기능 범위
- `UI_SPEC.md`: 홈과 분석 페이지의 화면 동작
- `TECH_SPEC.md`: 기술 구성, 데이터와 백업 규격
- `TEST_CHECKLIST.md`: 기능 및 화면 검증 항목
- `PROJECT_PROGRESS.md`: 개발 단계와 완료 기록
- `AGENTS.md`: AI가 개발할 때 지켜야 할 규칙

## 기술

- HTML
- CSS
- 순수 JavaScript
- 브라우저 로컬 저장소
- Node.js 기본 모듈을 사용한 개발용 로컬 서버

## 실행 방법

별도 패키지 설치 없이 프로젝트 폴더에서 다음 명령을 실행한다.

```powershell
node dev-server.mjs
```

브라우저에서 [http://127.0.0.1:4173](http://127.0.0.1:4173)을 열면 홈 화면을 확인할 수 있다. 서버를 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누른다.

`PORT` 환경 변수에 양의 정수를 지정하면 기본 포트 `4173` 대신 해당 포트를 사용한다.

```powershell
$env:PORT=5000
node dev-server.mjs
```

## 현재 구현 범위

- 오늘과 과거 날짜를 선택할 수 있는 월간 달력
- 행복·평온·설렘·슬픔·불안·화남 중 대표 감정 하나 선택
- 날짜별 일기 저장·조회·수정·삭제와 1,000자 제한
- 브라우저 로컬 저장소를 이용한 기록 유지
- 월별 감정 횟수와 감정별 날짜순 기록 목록
- 전체 기록 JSON 백업 다운로드 및 확인 후 복구
- 기록이 없는 달과 감정의 빈 상태 안내
- 768px 기준 PC·모바일 반응형 화면
- 키보드 포커스, 44px 조작 영역, 본문 바로가기 링크
- 외부 서버·추적 도구·외부 라이브러리 없는 정적 웹 구성

## 사용 방법

1. 홈 달력에서 오늘 또는 과거 날짜를 선택한다.
2. 대표 감정 하나를 누르고 오늘 있었던 일을 작성한다.
3. `저장하기`를 누른다. 저장된 날짜를 다시 누르면 수정하거나 삭제할 수 있다.
4. `분석` 메뉴에서 월별 감정 횟수를 확인하고 감정 카드를 눌러 관련 기록을 읽는다.
5. 홈의 `데이터` 메뉴에서 기록을 JSON 파일로 백업하거나 이전 백업을 복구한다.

## 데이터 안내

- 일기는 현재 브라우저의 로컬 저장소에만 보관되며 외부로 전송되지 않는다.
- 다른 브라우저나 기기와 자동 동기화되지 않는다.
- 브라우저 데이터를 삭제하기 전에는 `데이터 → 백업하기`로 파일을 보관하는 것이 좋다.
- 복구하면 현재 기록 전체가 선택한 백업 파일의 기록으로 교체된다.

## 테스트

Node.js 기본 테스트 러너로 날짜, 저장소, 유효성 검사와 백업 규격을 확인할 수 있다.

```powershell
node --test
```

Chrome과 Edge의 격리 프로필을 이용한 브라우저 스모크 테스트는 `tests/browser-smoke.mjs`에 포함되어 있다.
